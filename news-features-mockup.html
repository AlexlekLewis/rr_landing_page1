How It Works

1

Homepage preview strip. Shows your latest 3 features (1 lead + 2 smaller). Matches your current homepage style exactly — same fonts, pink accents, rounded cards. Links to the full page.

2

The /features page. Infinity scroll — more articles load as you scroll. Articles expand open in place, so nobody gets taken off the page.

3

Three content types. News/articles (full text on-site), external links, and YouTube videos — each with a coloured type badge.

4

Pinned & timed. Important features can be pinned to the top for a set period, then automatically drop down the feed.

5

Cross-linking for upsell. Every feature links to related features and to relevant programs — turning readers into enrolments.

6

You send, I build. You fill in a simple template per feature (title, type, summary, body/link/video, image, tags, related programs, pin date) and I add it via code.

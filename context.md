# Project Context

## Project Overview
This project is a landing page for the **Rajasthan Royals Academy Australia Elite Programme**.
The goal is to drive applications for a T20 cricket academy.
The content and structure are primarily driven by `V2 ROYALS ELITE PROGRAMME LANDING PAGE.md`.

## Tech Stack
- **Framework**: React 19 (Vite)
- **Styling**: Tailwind CSS 4
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Backend/Database**: Supabase (Client library installed)
- **Linting**: ESLint

## Project Structure
- `src/`: Source code
  - `components/`: React components
  - `lib/`: Utility libraries (likely Supabase client configuration)
  - `assets/`: Static assets (images, etc.)
- `V2 ROYALS ELITE PROGRAMME LANDING PAGE.md`: Single source of truth for text content and layout requirements.

## Key Features
- Hero section with video.
- Testimonials and Success Stories.
- Program details (Elite Programme Overview).
- Coach and Mentor profiles.
- FAQ section.
- Application form.

## Conventions
- Use functional React components with Hooks.
- Use Tailwind CSS classes for styling.
- Keep components modular in `src/components/`.
- Refer to `V2 ROYALS ELITE PROGRAMME LANDING PAGE.md` for copy and structural changes.
